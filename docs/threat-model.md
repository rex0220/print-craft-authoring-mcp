## 1. 範囲

| 含める | 含めない |
| --- | --- |
| print-craft MCP（Desktop の `.mcpb`、Claude Code のプラグインの `.mcp.json`）、プラグインのフック、共通の中核（core）、`instructions` と `pcraft_docs`、設定項目と秘密の値の渡し方、配布物（`.mcpb`、プラグイン、npm） | Claude Desktop / Claude Code そのもの、OS、kintone のサーバー、公式の kintone MCP の中身（Claude Code で今のまま使う）、kintone に入れた印刷屋プラグインそのもの |

今の CLI（テンプレート + npm の tools）は、中核を共有するので②④の規則が効くが、強制の境界は今の `safe-path.ts` と `.claude/settings.json`（今のまま）。

## 2. 守るもの

| ID | 守るもの | 守れなかったときの害 |
| --- | --- | --- |
| A1 | kintone の認証情報（API トークン、パスワード） | kintone のデータの読み出し・（パスワードなら）書き込み・設定の変更 |

## 3. 脅かすもの

| ID | 脅かすもの | 例 |
| --- | --- | --- |
| T1 | AI の誤り | 引数の取り違え、手順の抜け（normalize をしない）、別のフォルダー・別のアプリを触る、本番のフォルダーを直す |
| T2 | 指示の紛れ込み（プロンプトインジェクション） | レコードの値・既存の設定・項目のラベル・資料に「〜を実行せよ」が書かれていて、AI がそれに従う |
| T3 | 改変された作業フォルダー | 共有・clone したフォルダーの `node_modules`、設定ファイル、`environments.json` の削除・書き換え、symlink / junction で外を指す |
| T4 | 改変された印刷屋の zip | 本物の `PUBKEY` を写して中身を差し替えた zip（**受け入れた危険**。2026-10-09 Takashi） |
| T5 | 版の食い違い・古いプロセス | 更新の後も古い print-craft MCP が動き続ける、資料と中核の版が合わない |
| T6 | 実装の誤りによる漏れ | 秘密の値・レコードの値がエラー文・ログ・応答に混ざる |

範囲の外（受け入れる）: 同じ OS の利用者の権限で動く他のプロセス、パスの検査から書き込みまでの間のリンクの差し替え（TOCTOU。今の tools と同じく、AI と同じ OS の利用者の範囲の話として防がない）、OS や Claude のアプリそのものの侵害。
