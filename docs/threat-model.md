## 3. 脅かすもの

| ID | 脅かすもの | 例 |

| T1 | AI の誤り | 引数の取り違え、手順の抜け（normalize をしない）、別のフォルダー・別のアプリ・別の profile を触る |
| T2 | 指示の紛れ込み（プロンプトインジェクション） | レコードの値・既存の設定・項目のラベル・資料に「〜を実行せよ」が書かれていて、AI がそれに従う |
