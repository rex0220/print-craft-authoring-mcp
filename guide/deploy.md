# 反映方法（利用者に伝える）

保存した設定 JSON は、利用者が印刷屋の設定画面で取り込む（print-craft MCP は kintone に書き込まない）。

1. kintone のアプリの設定 → プラグイン → 印刷屋プラグインの設定
2. **設定をアップロード** → 保存したファイルを選ぶ → 取り込み方を選ぶ
   - 印刷屋の設定がまだ無いアプリ: 「全置換」
   - 既存の設定があるアプリにボタンを足す: 「追加」（同じ名前があれば「名前 (2)」）
   - 既存のボタンを差し替える: 「一部置換」（ボタンごとに置き換え先を選ぶ）
   - 一部置換と追加では、外部参照・Web フォント・メニューなどはアプリの今の設定のまま。取り込んだボタンは保存のときに印刷屋が検査し、項目が合わなければ保存されない
3. **保存する** → **運用環境に反映**
4. 詳細画面（一覧帳票なら一覧画面）でボタンを押して PDF を確かめる

確かめてほしい点（見た目、改行、ファイル名、保存先）を添える。

開発と本番を分けているとき（`environments.json`）: 作るのも直すのも開発の環境のアプリ。本番へは、利用者が開発で確かめた同じファイルを本番の設定画面でアップロードする（「追加」か「一部置換」。アプリが違うという注意は出るが取り込める）。特定の一覧に出したいボタンは、本番にアップロードした後に本番の設定画面で一覧を選んでもらう（一覧 ID はアプリごとに違う）。
